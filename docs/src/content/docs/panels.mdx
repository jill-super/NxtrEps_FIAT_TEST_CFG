Panels are the operator UI: buttons, switches, numeric inputs and displays bound to CAN signals or system variables. CANoe 8.5.98 format (`Vector.CANalyzer.Panels.*`, v8.5.98 — except `Panel1.xvp` on v8.2.98).

## `Fiasa326.xvp` — main panel (46 controls)

Control types: TextBox, StaticText, Button, CheckBox, ComboBox, LCD, LED, Switch, GroupBox, Start/Stop. Key bindings (`MESSAGES::*` sysvars):

- `pnlBCM_COMMAND_disable`, `pnlBSM1_disable`, `pnlMOT1_disable`, `pnlMOT3_disable`
- `CRC_BSMOff`, `MessageCounter_BSMOff` (fault injection for the BSM CRC/counter logic)

These drive the `on sysvar` handlers in `BCM.can` / `BSM.can` / `ECM.can` — toggling a checkbox enables/disables the corresponding IL message. See [System variables](./system-variables/) and [CAPL](./capl/).

## `trialpanel.xvp` — link/NTC test panel (83 controls)

The largest panel (82 KB, 83 controls, 74 bindings): `TrackBar`, `NumericUpDown`, LCDs plus start/stop controls. Bindings include:

- `LinkTestVariables::IgnitionCycle_TestCycleNumber`, `IgnCycle::VariableTime`
- `ReadNTCPanel::ClearNTCs`, `ReadNTCPanel::Message131/17D/3E9…` (NTC read/clear flows)

## `FiasaOld.xvp` — legacy XCP panel (24 controls)

Binds to XCP mirror sysvars (`XCP::SCIR::…`: `AbsHwPos_HwPosState`, `CmdIgnSts`, `EngSts`, `OpModeSts`, `Rte_AbsHwPos_HandwheelPosition_HwDeg_f32`) plus `VTS::Ignition::Active`. Superseded by `Fiasa326.xvp` for daily use.

## `Panel1.xvp` — minimal demo (3 controls)

A single Input/Output Box bound directly to the bus signal `CCAN;BCM;BCM_COMMAND;OperationalModeSts` (symbolic binding, not via sysvar). Useful as the smallest example of a signal-bound control.
