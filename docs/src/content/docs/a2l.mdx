The A2L file is the **ASAP2 description of the EPS application (RTE 4.00.00)** used by CANape/XCP to measure and calibrate the ECU. Written by **CANape 11.0.0**, ASAP2 version **1.60**, project `{a2l.project}`, module `{a2l.module}`, byte order `{a2l.byteOrder}`.

| Property | Value |
| -------- | ----- |
| File | `A2L/Rte_4.00.00.a2l` ({(a2l.size / 1024).toFixed(0)} KB, ~12.8k lines) |
| Measurements (`/begin MEASUREMENT`) | **{a2l.measurementCount}** |
| Groups (`/begin GROUP`) | **{a2l.groups.length}** (mostly `AbsHwPos.*` handwheel-position family) |
| Conversion methods (`COMPU_METHOD`) | **{a2l.compuMethods.length}** |
| Record layouts (`RECORD_LAYOUT`) | **{a2l.recordLayouts.length}** |
| Characteristics / functions / axis points | 0 / 0 / 15 — this file is **measurement-only** (no calibratable maps in this export) |

:::note
No `/begin CHARACTERISTIC` blocks: this A2L export describes observable quantities (sensor values, fault accumulators, status words) for the test bench, not tunable curves/maps.
:::

Naming convention: `<function>_<signal>_<type>` with AUTOSAR-ish suffixes — `_f32` (float32), `_u8/_u16` (unsigned), `_lgc` (boolean), `_M_` (measured). The biggest family is `AbsHwPos.*` (handwheel position: `HandwheelPosition_HwDeg_f32`, `CumMechMtrPosCRF`, `AlignedCumMechMtrPosCRF`, …) plus BSM1 CRC/counter fault accumulators (`BSM1CRCFltAcc_Cnt_M_u16`, `BSM1MsgCounterFltAcc_Cnt_M_u16`) and mode/status words (`OpModeSts`, `EngSts`, `CityModeSts`, `ESLampFailSts`).
