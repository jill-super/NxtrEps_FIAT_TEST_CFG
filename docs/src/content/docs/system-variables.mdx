## `sys.vsysvar` — the 52 bench variables

Namespaces: `MESSAGES` (51 vars) + `XCPResponse` (1 var, `ReturnVal`).

**Message disable switches** (int, written by panels, read by `BCM.can`/`ECM.can`/`IPC.can` via `on sysvar`):

- `pnlBCM_COMMAND_disable`, `pnlSTATUS_C_BCM2_disable`, `pnlSTATUS_C_IPC_disable`, `pnlBSM1_disable`, `pnlMOT1_disable`, `pnlMOT3_disable`

**CRC / counter fault injection** (read by `BSM.can`):

- `CRC_BSMOff`, `MessageCounter_BSMOff` — set to 1 to freeze CRC / counter updates on `BSM1`

**NTC (diagnostic trouble code) staging** (consumed by test/panel flows):

- `NTC1_AgingCnt`, `NTC1_DTCnum`, `NTC1_Parameter`, `NTC1_StatusByte` (same ×3 for NTC2, NTC3)

**Tx-rate / message-analysis probes** (float, used with `MessageAnalysis.can`):

- `SysVarAvgTxRate`, `SysVarMaxTxRate`, `SysVarMinTxRate`, `SysVarDataLength`, `VarTime` (start value 2000), `ReadSysVar`, `PWMOutputDC`

**Vehicle-state mirrors** (float):

- `SysVarVehSpd`, `SysVarSWA`, `SysVarPowerMode`, `SysVarEngineStatus`, `SysVarEngGenStatus4`, `SysVarEngCntrlReq`, `SysVarTransGenStatus`, `SysVarChassisGenStatus1`, `SysVarABSandTCStatus`, `SysVarVehStability`, `SysVarVehDynESCHybCE`, `SysVarDrvModeControl`, wheel speeds (`SysVarDrvnWheelGrndVelCE/HS`, `SysVarNonDrvnWheel…`, `SysVarWheelPulse`), steering (`SysVarSteeringTorqueCmdCE`, `SysVarLKASteeringTorqueCmdCE/HS`), VIN digits (`SysVarVINDigits2to9`, `SysVarVINDigits10to17`), `SysVarParkAssistParallelCE`

## How they connect

- **Panels → sysvars:** `Fiasa326.xvp` checkboxes bind to `MESSAGES::pnl*_disable`, `CRC_BSMOff`, `MessageCounter_BSMOff` (see [Panels](./panels/)).
- **Sysvars → CAPL:** `on sysvar MESSAGES::…` handlers call `ILDisableMsg` / `ILEnableMsg` (see [CAPL](./capl/)).
- **`SIGNALS.vsysvar`** is an empty placeholder (`<systemvariables version="4" />`) — reserved for future signal-bound vars.
- **`A2L/bl.vsysvar`** holds `_Statistics::CAN1::CANBusload` (float, %, 0–100) for bus-load display.
