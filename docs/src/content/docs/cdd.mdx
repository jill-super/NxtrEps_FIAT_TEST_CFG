## Migration log

`CDD/Load_migration_7.5.2101_to_8.2.106_Fiasa_326_327_4.00.00.log` ({migration.lines} lines) records the CANdela upgrade of the FIASA CDD from DTD **7.5.2101** to **8.2.106** (template `FIAT Standard enhanced Diagnostic Protocol on CAN`, save 21). Highlights:

- DTC status-mask migration (8.0.1): all 8 status bits kept as optional/supported.
- DID migration (8.1.1): packet types converted to DIDs — e.g. `Odometer` → DID 259, `Session_Control_Disabled` → DID 262, `Roe_Activation_State_1` → DID 263.
- Variant loads: `CommonDiagnostics` + `_FF_00_00_0002_00D2_P3272_P341_Next_Gen_A`.

## How to use the CDDs

1. In CANoe Diagnostics console, select the EPS description (`Fiasa_326_327_4.00.00.cdd`) for UDS work against the steering ECU, or `DSS.cdd` for bench/manufacturing functions.
2. Match service names above to the `Capl/traceLog.txt` entries (e.g. DID `0x0ADA` reads) — see [Traces & logs](./traces-logs/).
3. For XCP-based measurement instead of UDS, use the [A2L](./a2l/) description.
