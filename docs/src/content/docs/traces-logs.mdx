## `Capl/traceLog.txt` — diagnostic session ({tracelog.lines} lines)

A CANape/CANdela-style trace against `Nexteer_Electric_Power_Steering_P3272_P341_Next_Gen_A_1`: Tx DID reads, Rx positive/negative responses with decoded system-status bits. Representative lines:

- `[15:41:55] - Tx 22 0A DA …` → `Negative response: Incorrect message length or invalid format`
- `[15:42:09] - Rx 62 0A DA 08 …` → positive response, `System status 0x08` with per-bit decode (`DST Status NOT requested`, `Operative Conditions Not passed`, …)

## `Trace.blf` notes

`LOGG` magic, zlib-compressed `LOBJ` containers (standard Vector BLF). To inspect: CANoe → Measurement → Trace window → open `Trace.blf`, with the C-CAN + DSS databases loaded so IDs decode to the [DBC](./dbc/) names. To re-record: check the logging blocks in `Fiasa.cfg` (`VLogCfgData`, `Logging_PreFilter.blf`, ASC/MDF export paths).
