## How to re-run

1. Open `Canoe Config/Fiasa.cfg` in CANoe 8.5.98 (loads DBs, CDDs, sysvars, VT config).
2. Open Test Setup → load `Canoe Config/Test_FIASA.tse`.
3. Start measurement (VT hardware must be present — the init sequence drives `DigTrq*`, `Torque*`, `Position*` channels; see [VT System](./vt-system/)).
4. Execute the test node; compare against the archived `.xml`/`.html` verdict.

For the test logic itself (torque/position ramps, PWM outputs), read [`Init VT7001.can`](./capl/).
