## What is this repo?

This repository is the **test configuration for the FIASA electric power steering (EPS) program** (Fiat / Nexteer, P3271 / P3272 platforms). It is not application code — it is the complete Vector-tooling setup used to **simulate the vehicle, stimulate the EPS ECU, run diagnostics (CDD), measure/calibrate via XCP (A2L), and operate the bench from CANoe panels**:

- **CANoe 8.5.98** configuration (`Canoe Config/Fiasa.cfg`) wiring everything together: two CAN databases, two CDD files, system variables, CAPL simulation nodes, VT hardware, trace windows and logging.
- **C-CAN database** (`DBC/P3271_C-CAN [07339]_6A_R1_CR1664.dbc`, {ccan.messageCount} messages / {ccan.signalCount} signals, {ccan.nodes.length} ECUs) plus a small **DSS bench database** (`DBC/DSS.dbc`, {dss.messageCount} messages) for XCP/test support.
- **Diagnostics** (`CDD/Fiasa_326_327_4.00.00.cdd` — Nexteer EPS, {fiasa.counts.diagClasses} classes / {fiasa.counts.diagInstances} instances / {fiasa.counts.services} services; `CDD/DSS.cdd` — bench/manufacturing services).
- **Measurement & calibration** (`A2L/Rte_4.00.00.a2l` — {a2l.measurementCount} RTE measurements, ASAP2 v1.60, written by CANape 11).
- **Simulation & test logic** (`Capl/*.can` source + `*.cbf` binaries: BCM/BSM/ECM/IPC stubs, VT7001 init, EPS torque/position simulation, message-rate analysis, XCP/DLC tests).
- **Operator panels** (`Canoe Config/*.xvp` — Fiasa326, trialpanel, FiasaOld, Panel1) and **VT System** (`*.vtcfg` — 6 modules / 37 channels for power, torque, position, motor loads).
- **System variables** (`system_variables/sys.vsysvar` — 52 vars: message disables, NTC injection, Tx-rate probes; `A2L/bl.vsysvar` — bus-load probe).

## Tool versions pinned by this repo

| Tool | Version in repo | Evidence |
| ---- | --------------- | -------- |
| CANoe | **8.5.98 SP4, 32-bit PRO** | `Fiasa.cfg`, `*.tse`, `*.xvp` headers |
| VT System config | v3 (`VTSConfiguration version="3"`) | `Fiasa.vtcfg` |
| CANdela (CDD) | file **7.5.2101**, migrated to **8.2.106** | migration `.log` |
| CANape / ASAP2 | A2L written by **CANape 11.0.0**, ASAP2 **v1.60** | `Rte_4.00.00.a2l` header |
| CAPL report | CANoe.LIN.XCP 8.5.98, 2016-03-21 | `Init VT7001_report.xml` |

> **Note on binaries:** `.cbf` (compiled CAPL), `.blf` (trace), `.dmp` (crash dump) cannot be read as text. These docs explain what each one is, which source/config produced it, and how to open it — and parse everything around it.
