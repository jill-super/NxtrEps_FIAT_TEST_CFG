The repo is a flat bench configuration: six tool folders plus this docs site. No build, no source to compile — the "code" is the Vector configuration itself.

## Directory map

| Directory | What it holds | Key files |
| --------- | ------------- | --------- |
| `A2L/` | ASAP2 measurement description + CANape map settings | `Rte_4.00.00.a2l` (422 measurements), `Rte_4.00.00.INI`, `bl.vsysvar` |
| `CDD/` | CANdela diagnostic descriptions + migration log | `Fiasa_326_327_4.00.00.cdd` (EPS), `DSS.cdd` (bench), migration `.log` |
| `Canoe Config/` | CANoe config, panels, VT configs, test setups, CANape INI, trace & logs | `Fiasa.cfg`, 4× `.xvp`, 2× `.vtcfg`, 2× `.tse`, `CANape.INI`, `Trace.blf` |
| `Capl/` | CAPL sources, compiled binaries, test report, trace log | 8× `.can`, 6× `.cbf`, `Init VT7001_report.*`, `traceLog.txt` |
| `DBC/` | CAN databases + DBC-viewer layout | C-CAN `.dbc` (77 msgs), `DSS.dbc` (4 msgs), `.ini` |
| `system_variables/` | CANoe system variables | `sys.vsysvar` (52 vars), `SIGNALS.vsysvar` (empty placeholder) |
| `docs/` | This documentation site (Astro + Starlight) | `astro.config.mjs`, `src/content/docs/`, `src/data/`, `scripts/extract.py` |
