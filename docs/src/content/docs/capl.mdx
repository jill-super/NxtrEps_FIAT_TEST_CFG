CAPL nodes are the bench's behavior: ECU stubs, CRC/counter injection, VT stimulus, message-rate checks and XCP tests. **`.can` = human-readable source, `.cbf` = compiled binary** produced by the CANoe CAPL compiler (magic `CAPL`, not readable — always read the same-named `.can`).

| File | What it is |
| ---- | ---------- |
| `BCM.can` | BCM stub: `ILActivateClamp15()` on start; sysvar toggles disable/enable `BCM_COMMAND` and `STATUS_C_BCM2` |
| `BCM2.cbf` | Compiled only (no `.can` source in repo) — legacy/extra BCM branch |
| `BSM.can` | BSM stub with live **CRC-8 (poly 0x1D, init 0xFF) + message-counter** injection on `BSM1`; honors `MESSAGES::CRC_BSMOff` / `MessageCounter_BSMOff` sysvars |
| `ECM.can` | ECM stub: toggles disable/enable `MOT1` and `MOT3` via sysvars |
| `IPC.can` | IPC stub: toggle for `STATUS_C_IPC` |
| `Init VT7001.can` | **VT7001 bench init**: torque + position ramp simulation, NCS offsets, PWM duty outputs; executed by `Test_FIASA.tse` (last run: pass, 2016-03-21) |
| `EPS_VT_SIM_001.CAN` | Larger EPS/stimulus simulation (1,235 lines): handwheel torque & position loops, timers, VT analog outputs |
| `MessageAnalysis.can` | Generic **message-rate analyzer** (917 lines): samples any CAN ID, reports current/average/min/max rate + timeout handling |
| `XCPTest_Fiasa.CAN` | **XCP + DLC test suite** (1,711 lines): tester-present, DLC-length checks per ID, DTC read (`0x18DA30F1`), message-rate helpers |
| `UC_FREIN.can` | Brake (`IS_DYN_ABR_38D` / `0x38D`) checksum/counter helper (`applILTxPending`) |
