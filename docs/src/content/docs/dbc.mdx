Two databases, two buses:

- **C-CAN** — `DBC/P3271_C-CAN [07339]_6A_R1_CR1664.dbc`: the vehicle bus. **{ccan.messageCount} messages, {ccan.signalCount} signals**, ECUs `{ccan.nodes.join(', ')}`. Bound in `Fiasa.cfg` as database `CCAN` on network `CCAN`.
- **DSS bench bus** — `DBC/DSS.dbc`: minimal support DB for XCP/test. **{dss.messageCount} messages**, ECUs `{dss.nodes.join(', ')}`. Bound as `DSS` on `Can2`.

The `.ini` next to the C-CAN db (`P3271_C-CAN [07339]_6A_R1_CR1664.ini`, 165 lines) only stores DBC-viewer column layouts (`View_Nodes`, `View_Messages`, `View_Signals`, …) — no bus semantics.

## ECUs on C-CAN

| ECU | Role in this bench |
| --- | ------------------ |
| `BCM` | Body control — transmits `BCM_COMMAND`, `BATTERY_INFO`, `STATUS_C_BCM1/2` |
| `BSM` | Brake system — transmits `BSM1/2`, `BSM_YRS_DATA`, `WHEEL_*`, `STATUS_BSM` |
| `ECM` | Engine — transmits `MOT1–4`, `MOT_TRANSMISSION`, `STATUS_ECM` |
| `EPS` | **The unit under test** — transmits `GE`, `XcpSlave`/`GliwaSlave`, diag responses |
| `IPC` | Cluster — transmits `STATUS_C_IPC`, `TIME_DATE` |
| `MTA` | Transmission — transmits `TRANSMISSION1/2`, `SELMOT3`, `STATUS_TRANSMISSION` |
| `ORC` | Occupant restraint — transmits `ORC_YRS_DATA`, `IMPACT_INFO`, `STATUS_ORC` |
| `PAM` | Park assist — transmits `PARK_INFO`, `STATUS_PAM` |
| `DIAG_TEST` | Tester node — transmits `XcpMaster`/`GliwaMaster` + all `DIAGNOSTIC_REQUEST_*` |

## How to read a DBC line

```
BO_ 242 BSM1: 8 BSM
 SG_ CRC_B1 : 7|8@0+ (1,0) [0|255] ""  Vector__XXX
```

`BO_` = message (ID 242, name `BSM1`, 8 bytes, sent by `BSM`). `SG_` = signal (`CRC_B1`, starts at bit 7, 8 bits, Motorola, unsigned, factor 1, offset 0). The CAPL `BSM.can` node computes exactly this CRC and the message counter — see [CAPL](./capl/).
